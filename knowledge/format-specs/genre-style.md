# Theme setting guide

> Theme is the first step in Phase 2 - decide on the theme and then talk about the
> world view and characters. After selecting, write `settings/genre-setting.md`. There
> are 5 fields in total: selected genre/meeting genre/rhythm rules/avoiding
> routines/genre taboos. Chat one by one and write one by one.

---

## Choose the subject first

This step is not a field written into the file, but a prerequisite for talking about
other fields - only when the topic is decided will you know what aspects to talk about.

### How to chat: Let the author tell the story and you be the judge.

Don’t give authors lists of categories. The author must have something he wants to write
at this point, but he just doesn’t understand the terminology. Ask directly:

> "What kind of story do you want to write? Don't worry about the genre. Just tell me
> who the protagonist is, what world he is in, and what he does."

**No matter what the author said, after you listen, do two things:**

1. Extract **3 key signals** from the author's description - era background, power
   system, and core conflict type
2. Use the table below to determine the best matching type

| Key Signals | Match Type |
|---------|---------|
| Modern city + daily emotions + real life | Urban daily life |
| modern city+golden finger system+wild idea fantasy | urban wild idea |
| Modern city + farming construction + business war workplace | Urban farming |
| Modern city + national cultivation + spiritual energy recovery | Urban high martial arts |
| Modern City + Cultivation/Cultivation System | Urban Cultivation |
| Modern city + Return of the God of War + live-in son-in-law transformation | God of War live-in son-in-law |
| Ancient background + farming / court / struggle for hegemony | Ancient history |
| ancient background+golden finger+wild idea | historical wild idea |
| Anti-Japanese War + Military/Spy War | Anti-Japanese War Spy War |
| Another world + high martial arts + useless counterattack | Traditional xuanhuan (Eastern fantasy) |
| Different world + wild idea setting | xuanhuanwild idea |
| Modern + Detective/Mystery/Criminal Investigation | Suspense Criminal Investigation |
| Modern + Supernatural/Feng Shui/Horror | Suspense and Supernatural |
| Weird recovery + weird rules + thriller game | Suspenseful wild idea |
| Apocalypse/Zombie/Interstellar/Mecha/Future Technology | Science Fiction Apocalypse |
| Western World + Magic/Fighting/Fantasy | Western Fantasy |
| Eastern World + Immortal Cultivation / Daoist Cultivation / True Cultivation | Eastern xianxia (immortal cultivation) |
| Fan adaptation of film and television drama | male-oriented spin-off |
| Games/anime/two-dimensional fan fiction | animation derivatives |
| Online Games/Competition/Sports/World Gamification | Game Sports |

**Show it to the author for confirmation after judgment:**

> "It sounds like what you wrote was **{Type}** - {a reason}. Is that correct?"

✅ Correct:
> Author: "I want to write about an ordinary office worker who suddenly sees the death
> countdown above other people's heads one day. He tries to save these people, but
> finds that the countdown is getting shorter and shorter." → Signal extraction:
> modern city (office worker) + golden finger system (death countdown) + saving
> people's backlash → Judgment: **urban wild idea (urban-brained)** → Confirmation:
> "It sounds like you are writing about urban wild idea - a modern urban setting where
> the protagonist gains special abilities, but does this come with a price? "

❌ Error:
> Author: "I want to write a story." → Continue to ask: "What kind of person is the
> protagonist? Where does the story take place? Ancient times or modern times?"

**Conditional branch:**

| The author says | How to pick up |
|--------|--------|
| "Yes, that's it" | Enter field 1 and write the selected type |
| "Not quite right, more like XX" | Re-judge according to the author's correction, or directly select manually |
| "Still don't know what type it is" | "It doesn't matter, tell me whether there are supernatural powers in your story? Ancient or modern? - Once these are decided, it will be easy to classify." |
| "I don't want to choose a genre" | "It's easy to talk about the worldview only if the subject matter determines the worldview - xianxia and the worldview of the apocalypse are completely different. Determine the subject matter first, and then the worldview can be discussed accurately." "Don't choose yet" is also a valid answer, and you can make up your mind at any time later. |

**Judgment Criteria:** Did the author explicitly mention a genre (or "not choose yet")?
Ambiguous → Keep chatting.

**No need to read external files. ** Each field below has multiple subject examples
inline for direct reference.

## Field 1: Selected Type

**What to write:** Type id + Chinese name, one line.

```
xianxia, oriental xianxia
```

The id uses lowercase English hyphens, and the Chinese name uses an expression approved
by the author. If you select the fusion type, label the main type + overlay features:

```
urban-brained, urban wild idea (superimposed with suspense criminal investigation elements)
```

**Judgment Criteria:** After reading, you will be able to know what the subject matter
is and what elements it incorporates.

## Field 2: Satisfaction Type

**What to write:** 3-5 kinds of "satisfaction" readers want to get from this subject,
and describe the core attraction in one sentence for each type.

### The underlying model: repression → acquisition → release → re-repression

The satisfactions of all genres share the same underlying cycle. Writing clearly about
different topics just puts a different skin on this cycle:

```
Repression (being looked down upon/lack of resources/being at the bottom)
  → Obtain (adventure/breakthrough/key clue/ally)
    → Release (face-slapping/showing off/reversal/solving the case)
      → Repress (Stronger Opponent/New Mystery/Higher Level Opponent)
        → Loop...
```

The lack of "suppression" is directly replaced by "acquisition", and readers will not
feel happy - without comparison, there will be no satisfaction. Without "repression",
readers feel that the story is coming to an end - there is no motivation to continue
pursuing it.

**Different themes just give this cycle a different skin:**

| Theme | Repression stage (what is missing) | Acquisition stage (what to get) | Release stage (how to feel good) | Re-repression (new pressure) |
|------|------------------|-------------------|------------------|----------------|
| Eastern xianxia | Poor spiritual roots/few resources/being looked down upon | Heavenly materials and earthly treasures/practices/breakthroughs | Realm crushing/face-slapping | Higher realms/sect games |
| Urban wild idea | Ordinary social beast/no money and no power | golden finger/ability awakening | pretense/counterattack | stronger ability person/organization |
| Suspense criminal investigation | Clues interrupted/cheated/misled | Key evidence/breakthrough | Reasoning to solve the case/reversal | Bigger conspiracy/new mystery |
| Ancient history | Suppressed by political opponents/financial constraints | Talents/resources/holy relatives | Court comeback/reforms effective | New factions/external threats |
| Daily life in the city | Unsatisfactory work/emotional conflicts | Turnaround/noble person/enlightenment | Resolving conflicts/warming of relationships | New problems/new conflicts |

**So when chatting, don’t ask “What’s the satisfying payoff?”, just ask:**

> "With your subject matter, what do readers most want to see the protagonist get rid
> of, gain, and achieve?", What to get rid of = repression stage, what to get =
> acquisition stage, and what to achieve = release stage.

**Judgment criteria:** Can each satisfaction type explain the corresponding three stages
of "suppression → acquisition → release"? Can't → Readers won't feel happy without
depression.

## Field 3: Rhythm Rules

**What to write:** Three rules - rhythm tendency, tension cycle, and upper limit of
foreshadowing.

### Rhythm tendencies

Does this chapter advance the plot or set up the atmosphere? When you look at the volume,
is it tight throughout or is it relaxed and relaxed? This does not determine how to
write each specific chapter, but it determines the overall rhythm of the volume. Just
describe it in one sentence, no precise measurement is required.

| Tendency | Meaning | Suitability |
|------|------|------|
| More action | Conflict/battle/confrontation-based, fast-paced | feel-good fiction, passionate, fast-paced upgrades |
| Too much foreshadowing | Focus on information/atmosphere/daily life, slow pace | Suspense, daily life, slow heat |
| Alternate relaxation and relaxation | Give a breather after a few tense chapters | Common to most themes |
| Tight throughout | Almost no routine and buffering | Infinite flow, apocalypse, strong suspense |

**How to chat:**
> "Does your story have a fast pace or a slow pace? - How many chapters does it have
> to have a small climax? Can you accept that there are several consecutive chapters
> that do not advance the story?"

### Tension Cycle

How many chapters will there be a small climax and how many chapters will there be a big
climax.

**Rule:**
- feel-good fiction: small climax in chapters 3-5, big climax in chapter 10
- Suspense: small climax in chapters 4-6, big climax in chapter 15
- Daily: small climax in chapters 5-8, big climax in chapter 20

### Upper limit of foreshadowing

"There is no progress for several consecutive chapters at most." Readers will abandon
the book if it exceeds this limit.

**Range Reference:** Fast-paced 2 chapters, Medium-paced 3 chapters, Slow-paced 4
chapters.

✅ Correct (xianxia fast pace):
> - Rhythm tendency: more action - Tension cycle: a small climax in Chapter 3-5, a big
> climax in Chapter 10 - Upper limit of foreshadowing: up to 2 consecutive chapters of
> foreshadowing, and there must be progress in Chapter 3

✅ Correct (suspenseful and slow-burning):
> - Rhythm tendency: too much foreshadowing - Tension cycle: small climax in chapter
> 4-6, big climax in chapter 15 - Upper limit of foreshadowing: up to 3 consecutive
> chapters of foreshadowing, and there must be an event to advance in chapter 4

❌ Error:
> The rhythm is moderate, fast when it should be and slow when it should be - if it is
> said, it is not said.

**Judgment criteria:** Will the agent "know it but don't know how to execute it" after
reading it? Would → Not specific enough.

## Field 4: Avoid routines

**What to write about:** This is a plot that readers are tired of seeing. ≥3 items.

It's not that you can't write routines, but you can't write them unconsciously - before
writing, you need to know "this is a routine", and then decide whether to subvert it,
bypass it, or admit it but write better.

**How to chat:**
> "Is there anything about this subject that you don't want to write about? - It's
> that old trick of knowing the ending as soon as you see the beginning."

The author may list things that need processing:

| The author said | Written |
|---------|------|
| "I don't want to write about the cliche auction face-slapping" | The auction must be face-slapping |
| "Don't jump off a cliff to have an adventure" | The protagonist must have an adventure if he jumps off a cliff |
| "If you don't want the protagonist to come up, you will be invincible" | The protagonist will be S-level when he awakens |

✅ Correct:
> If the protagonist jumps off a cliff, he will surely encounter an adventure - if he
> really jumps off a cliff, there may not be an adventure, but it may be an ambush.

❌ Error:
> Don’t write routines - it’s too broad, what counts as a routine?

**Examples of each theme (direct reference):**
- xianxia: A chance encounter by jumping off a cliff, face-slapping at the auction,
  being looked down upon in the entry test, high-level hidden strength shocked the
  audience
- Urban wild idea: The protagonist awakens to be S-level, the special management
  department is full of trash, the superpowers are too poor to eat, and the female
  character is only responsible for rescuing injuries.
- Suspense criminal investigation: the first witness is the murderer, the most unlikely
  murderer, the genius detective sees through it at a glance, and the final boss is
  always an acquaintance

**Judgment criteria:** Can each item be included in a 5-minute video of "complaining
about Internet novel routines"? Able → Qualified.

## Field 5: Type taboos

**What to write about:** Things that must not appear in this subject matter - readers
will abandon the book if it is written, and the genre does not hold up.

Taboos are not something you can "avoid as much as possible"; they are things that
change the flavor of the entire book.

**Common taboos are divided into three categories:**

| Category | Meaning | Example |
|------|------|------|
| The system collapses | The self-consistency is broken | The combat power fluctuates, the cultivation reaches the sky in one step, and the magic weapon can be used at will |
| The subject matter is misplaced | Things that should not be included in the subject matter | The world of xianxia talks about equality for everyone, and modern values appear in ancient times |
| Promises broken | Core experience destroyed | Mystery novels rely on the supernatural to solve crimes, while apocalyptic novels have no pressure to survive |

**How to chat:**
> "What do you think you should never write about this subject? - If you write about
> it, readers will say, 'What the hell is this?'"

If the author can't tell, ask for examples based on the chosen topic:

> "The collapse of combat power is a common minefield in xianxia's novels - do you
> mind? What about the influx of modern values into the world of cultivation?"

✅ Correct (xianxia):
> - Prohibit the collapse of the power system - combat power cannot rise or fall for
> the convenience of the plot - Prohibit modern values from entering the world of
> cultivation

❌ Error:
> Don’t write too outrageously - what counts as outrageous? Who defined it?

**Examples of each theme (direct reference):**

| Subject matter | Common taboos |
|------|---------|
| Eastern xianxia | Combat power collapsed, cultivation reached the sky in one step, modern values intruded, magic weapons were set at will, and the catastrophe was just a formality |
| Urban wild idea | Super powers have no price, the government is completely unaware, the protagonist is omniscient and omnipotent, and the system logic is inconsistent |
| Suspenseful criminal investigation | Supernatural case solving (non-supernatural themes), the murderer's motive is far-fetched, clues appear out of thin air, and the villain uses his wits |
| Ancient history | Modern thoughts travel through time, technology jumps too fast, historical figures are reduced to pieces, and the golden finger is too powerful and unrestricted |

**Judgment criteria:** Can the author imagine "what it would be like to write in
violation of this taboo"? Can't → be too abstract.

## Write File

Write `settings/genre-setting.md`, Markdown format. Full format reference:

```markdown
# Theme settings

## Selected type
xianxia, oriental xianxia

## Satisfy Type
- Realm breakthrough (hard power jump)
- Secret Treasure Hunting (Battle for Resources)
- face-slapping counter-kill (reverse evaluation after crushing with strength)
- Battle of the avenues (conflict of ideas vs. duel of strength)

## Rhythm Rules
- Rhythm tendencies: more action
- Tension cycle: a small climax in chapters 3-5, a big climax in chapter 10
- Upper limit of foreshadowing: up to 2 consecutive chapters of foreshadowing, and there must be progress in Chapter 3

## Avoid routines
- The protagonist must have an adventure if he jumps off a cliff
- Must-have face-slapping at the auction
- Entry tests will be looked down upon

## Type taboos
- Prevent the collapse of the power system
- It is forbidden to practice cultivation and reach heaven in one step
- Prevent modern values from entering the world of cultivation
```

## How each field is used downstream

Writing into `settings/genre-setting.md` is not the end point, each field has a
corresponding consumption link. Agent must read the corresponding fields when writing
direction proposals/chapter outlines/prompt words, otherwise it will be written in vain:

| Field | Who uses it | How to use it |
|------|------|--------|
| Selected type | `prompt-crafter agent` assembly prompt word | Read the selected type in settings/genre-setting.md, go to `.claude/knowledge/genre-example.md` and get `prompt_segment` to inject the prompt word |
| Satisfaction type | `chapter-planner agent` direction proposal | The proposal in this chapter must fulfill at least 1 satisfaction type, if one paragraph is not fulfilled = the reader will wait in vain for a chapter |
| Rhythm tendencies | `chapter-planner agent` direction proposal | Control the number of consecutive chapters of the same type (for example, "too much action" cannot have 3 consecutive chapters all climaxing, and readers will be unable to hold back) |
| Tension cycle | `updater-archive skill` sliding window review | Exceeding the upper limit of the tension cycle and not having a small climax → Remind the author that "the rhythm may be risky" |
| Upper Limit of Foreshadowing | `chapter-planner agent` Direction Proposal | When the number of consecutive foreshadowing chapters approaches the upper limit, the proposal must push a direction with progress |
| Avoid routines | `writer agent` quality gate control | Check whether the text hits the pattern in the avoid_cliches list |
| Type Taboo | `prompt-crafter agent` Assembly Prompt Word | Taboo writing in the "Writing Principles and Taboos" section of the prompt word, subagent must not violate |

**Rules:** If any of the above fields is empty or has only placeholder values, the Agent
corresponding to the consumption link will make its own judgment in the absence of
constraints. If a certain chapter doesn't sound right when written, first check "Have
you read genre-setting.md during the consumption process?"

## Acceptance: Use backcasting from downstream

Acceptance is not about "whether it is written", but about "whether it can be used
downstream". Each field simulates a consumption scenario to verify:

### Selected type

| Acceptance method | How to inspect |
|---------|--------|
| Is there | a type id or "no selection yet", not empty |
| Should it or not | This is confirmed by the author, not guessed by the Agent |
| Correct | In the follow-up `prompt-crafter agent`, we need to go to `.claude/knowledge/genre-example.md` to find the corresponding file based on this id. If the id is written incorrectly, it cannot be found. → Verification: Go to `.claude/knowledge/genre-example.md` to see if the corresponding file exists? |

### Satisfy Type

| Acceptance method | How to inspect |
|---------|--------|
| Is there | ≥ 3 items |
| Should it or not | Each entry is a specific description of attraction, not an abstract label of "cool" or "hot-blooded" |
| Right | **Direction Proposal Stage** These 3-5 items should be used to determine "which of the items fulfilled in this chapter satisfies the type". If a certain item is too broad ("hot-blooded"), the Agent will not be able to tell "whether this chapter satisfies this item" when making direction judgments. → Verification: Pick one item and ask, "What is written in this chapter that fulfills this item?" Can you answer it → Passed |

### Rhythm Rules

| Acceptance method | How to inspect |
|---------|--------|
| Is there any | Rhythm tendency + tension cycle + foreshadowing upper limit all have values |
| Should or should not | The three items are all specific and executable descriptions, not "faster if necessary" |
| True or not | **Sliding window review** should use rhythm tendency to judge whether the actual rhythm deviates from the expectation. **Direction Proposal** Use the upper limit of bedding to avoid continuous bedding exceeding the limit. If the tension cycle writes "a small climax in chapters 3-5" but there is no climax in the actual chapter 8, the deviation must be found. → Verification: Read the chapter titles and emotional states of the 5 chapters in the previous cycle, and ask "Have you deviated from the rhythm tendency?" |

### Avoid routines

| Acceptance method | How to inspect |
|--------|--------|
| Is there | ≥ 3 items |
| Should it or not | Each line is a specific section ("Jump off a cliff to get an adventure"), not a broad concept ("Don't use routines") |
| Correct | **Text Quality Access Control** Use this list to scan the text. If an article reads "Don't write too vulgar", even if you scan the script and look through the entire text, you won't be able to determine "what counts as vulgar". → Verification: Show the list to a person, can he or she say "this text hits this routine"? |

### Type taboos

| Acceptance method | How to inspect |
|--------|--------|
| Is there | ≥ 2 items |
| Should it be done | Every conceivable violation of it would be like, not "Don't write too outrageous" |
| Correct or not | **Prompt word assembly** You should write taboos into the "Writing Principles and Taboos" section. If an article is written "Prohibit system collapse", the subagent will not know "what to write to be considered a collapse" after reading it. → Verification: Rewrite it into a form that can be judged by the subagent - "It is forbidden to have high and low combat power: in the previous article, it was written that the golden elixir cannot defeat the foundation building, and in this chapter, it cannot be written that the golden elixir that builds the foundation in seconds" |
