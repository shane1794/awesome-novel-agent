Four-Dimension Volume Outlines

9 Agents Advance Automatically

Volume outlines, chapter outlines, body text, reviews, and archiving flow automatically; you only review and decide, never memorize the process.

Plot Simulation Sandbox

02

Doesn't sound like you?

It learns on import and sounds more like you with every chapter

Style Distillation

Drop novels you love into the sample library and it automatically distills quantitative parameters like sentence length and dialogue share.

Dynamic Memory

Every revision's feedback settles into memory automatically; high-frequency rules are promoted to permanent rules, so a mistake corrected once is never repeated.

24 Genre Profiles

Preset profiles for xianxia (immortal-hero fantasy), urban, suspense, historical, and more, with character tendencies and narrative tone ready to use.

03

Smells like AI?

Machine tone and logic holes get stopped before archiving

De-AI Flavor

Prompt assembly injects anti-AI rules, and a six-gate pipeline checks and scores the draft after writing.

Foreshadowing Tracker

Automatically scans for unpaid and newly planted hooks and reminds you to close them, so buried hooks are never forgotten.

Character Status

Each chapter's archiving automatically updates character status and emotional arcs, so the AI remembers what happened to them next chapter.

Pacing Check

Automatic alerts after 3 straight high-tension chapters or 2 flat ones, so readers never drop the book.

Start Creating

Three steps, from zero to chapter one

Step 1 · Install

Say One Sentence to Your AI

Open any supported AI terminal and say help me install awesome-novel-agent, the repo is at https://github.com/modoojunko/awesome-novel-agent. The AI runs the install script itself, no copy-pasting commands.

Step 2 · Initialize

Generate the Project Skeleton

In your novel's folder, enter /awesome-novel (or "help me write a novel") to generate the project structure for worldview, characters, and outline, then start the setup discussion.

Step 3 · Write

Enter the Writing Loop

@novel-agent or "help me keep writing" enters the loop. Common commands: write the next chapter / run a simulation / full auto mode.

FAQ

I can't code. Can I install it?

Yes. One sentence to your AI completes the install, with no copy-pasting commands at any point.

What if the generated text smells like AI?

The default is a "low AI flavor" setup: common machine-tone patterns are banned, and drafts are auto-checked. Your edits are also recorded as your own rules.

Can I use my own writing style?

Yes. Import reference samples for automatic distillation, or write it straight into the style file; later chapters all follow it.

Can I change the setup halfway through?

Just say "change XXX in the worldview" at any time, and the agents sync the later chapters.

Can old projects migrate?

After upgrading, the old format is auto-detected and migration is guided, with the original files kept as backup.
